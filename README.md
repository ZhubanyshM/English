# LingoSpark

Запуск локальной версии с регистрацией, SQLite и озвучиванием:

```powershell
node server.js
```

После этого откройте [http://localhost:3000](http://localhost:3000). Не открывайте `index.html` двойным кликом: для создания аккаунтов нужен запущенный сервер SQLite.

Первый зарегистрированный пользователь становится администратором. Пароли сохраняются в базе только как защищённые хэши.
